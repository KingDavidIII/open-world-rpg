# v0.9.0 Sprint 1 — Core Playability

## Goal

Turn the v0.8.0 voxel systems into a reliable first-person interaction layer without
introducing menus, crafting, progression, combat, or other Sprint 2/3 concerns.

## Delivered contracts

### Input ownership

- Gameplay movement and jumping are active only while the game owns the mouse.
- Losing window focus releases the mouse and cancels active mining.
- The first click after a released cursor reacquires input without also mining or placing.
- Escape releases captured input; a second Escape exits.

### Movement

- WASD input is normalised so diagonal movement has no speed advantage.
- Walking and sprinting remain frame-time based.
- Sprint and jump stamina policies remain authoritative in `PlayerVitals`.
- Fly-mode vertical controls are paused whenever gameplay input is not captured.

### Targeting and reach

- Mining and placement are validated by `VoxelInteractionController` before mutation.
- The interaction controller independently enforces the configured reach distance.
- Preview validation is side-effect free and uses the same policy as the committed action.
- Target and placement destinations are exposed as deterministic preview coordinates.

### Placement safety

Placement is rejected when:

- no target is available;
- the target is outside interaction reach;
- the selected slot is empty or contains a tool;
- the destination is outside supported world height;
- the destination is already occupied; or
- the destination intersects the player collision body.

### Player feedback

- Mineable targets use an amber outline.
- Invalid mining targets use a red outline.
- Valid placement destinations use a green outline.
- Invalid placement destinations use a red outline.
- Contextual interaction instructions appear above the hotbar.
- Failed actions produce readable timed feedback.
- A built-in control panel is toggled with F1 or H.
- Releasing the mouse shows a clear click-to-resume overlay.

## Explicit exclusions

- Inventory screen
- Drag/drop slot management
- Crafting
- Main menu and pause menu
- New World / Continue flow
- Progression objective
- Combat, creatures, quests, structures, and advanced biomes

These remain assigned to later v0.9.0 macro-sprints.
