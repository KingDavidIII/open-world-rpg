# v1.0 Manual Playtest Checklist

Use a fresh data directory for the clean-start pass and preserve a second directory
for recovery testing. Record each result as Pass, Fail, or Blocked. Any crash,
progression dead end, save loss, unrecoverable input state, or repeatable rendering
failure is release-blocking.
